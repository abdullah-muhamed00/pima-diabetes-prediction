# pima-diabetes-prediction
A machine learning model for diabetes prediction using the Support Vector Machine (SVM) algorithm trained on the Pima Indians Diabetes Dataset

# Diabetes Prediction using Machine Learning

## 📌 Project Overview

This project uses Machine Learning to predict whether a patient has diabetes based on medical diagnostic data.
The model is built using the **Support Vector Machine (SVM)** algorithm.

The dataset used in this project is the **Pima Indians Diabetes Dataset**.

---

## 📊 Dataset

The dataset contains several medical features such as:

* Pregnancies
* Glucose
* Blood Pressure
* Skin Thickness
* Insulin
* BMI (Body Mass Index)
* Diabetes Pedigree Function
* Age

The target variable:

* **0 → No Diabetes**
* **1 → Diabetes**

---

## ⚙️ Technologies Used

* Python
* NumPy
* Pandas
* Scikit-learn
* Jupyter Notebook

---

## 🧠 Machine Learning Model

The model used in this project is:

* **Support Vector Machine (SVM) with Linear Kernel**

Steps in the project:

1. Data Loading
2. Data Preprocessing
3. Data Standardization using StandardScaler
4. Splitting the data into training and testing sets
5. Training the SVM model
6. Making predictions
